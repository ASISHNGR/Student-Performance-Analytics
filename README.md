# 📊 Student Performance Analytics

## 📌 Project Overview

Student Performance Analytics is a data analytics project designed to analyze students' academic performance using Oracle SQL, Python, and Power BI.

The project demonstrates the complete data analysis workflow, from database design and SQL querying to visualization and reporting.

---

## 🎯 Objectives

- Analyze student academic performance.
- Identify top-performing and low-performing students.
- Compare subject-wise performance.
- Generate meaningful insights using SQL.
- Visualize results with Power BI.
